# 🔐 Full Authentication System using Core Java

A console-based **Authentication System** built using **Core Java** that demonstrates user authentication, file handling, object-oriented programming (OOP), and input validation.

This project was developed as part of my Java learning journey to understand how authentication systems work behind the scenes.

---

## 📌 Features

- 👤 User Registration
- 🔑 Secure Login
- 🔒 Change Password
- ❓ Forgot Password
- 👤 View User Profile
- 🚪 Logout
- 💾 File-Based Data Storage
- ✅ Input Validation
- ⚠️ Exception Handling
- 🧱 Modular Object-Oriented Design

---

## 🛠 Technologies Used

- Java (Core Java)
- Object-Oriented Programming (OOP)
- File Handling
- ArrayList
- Exception Handling
